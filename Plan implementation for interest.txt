REMINDER STRATEGY SYSTEM

VERY important.

Instead of raw cron settings.

Use:

Reminder Strategies
Gentle
Low frequency.

Balanced (Recommended Default)

Adaptive reminders.

Aggressive

Daily reminders + escalation.

Recommended Strategy Behavior

| Stage        | Gentle   | Balanced | Aggressive |
| ------------ | -------- | -------- | ---------- |
| Before Due   | once     | once     | daily      |
| 1-3 overdue  | every 2d | daily    | daily      |
| 4-14 overdue | weekly   | every 2d | daily      |
| 15+ overdue  | weekly   | every 3d | daily      |

RECOMMENDED REMINDER FLOW
FLOW 1 — Scheduler

Laravel Scheduler runs every 5 minutes.

$schedule->command('reminders:process')
    ->everyFiveMinutes();

FLOW 2 — Reminder Processor

Command:

  php artisan reminders:process

Responsibilities:

  -find loans needing reminders
  -evaluate reminder rules
  -prevent duplicates
  -dispatch queue jobs

FLOW 3 — Queue Jobs

Job:

SendTelegramReminderJob

Responsibilities:

  -render template
  -replace placeholders
  -send Telegram message
  -store reminder log

GROUP VS DM STRATEGY

IMPORTANT.

DM Reminders

Can be:

  daily

because private.

Group Reminders

Should be:

  rate-limited

Recommended:

  -due date
  -3 days overdue
  -7 days overdue
  -escalation stages

NOT every day.
