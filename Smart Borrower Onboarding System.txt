Smart Borrower Onboarding System — Implementation Plan

The goal is:

Make borrower creation feel modern, automated, and SaaS-style
WITHOUT making the system overly complex.

FINAL UX GOAL

Instead of this:

Admin manually types:
  - Telegram ID
  - Username

Your final UX becomes:

   System auto-detects Telegram information
   Admin only fills missing business data

This is MUCH more professional.

LARAVEL IMPLEMENTATION STRUCTURE

IMPORTANT BUSINESS RULES

Rule 1
Never trust Telegram usernames.

Why:

  Usernames can change.

Always identify by:

  telegram_user_id

Rule 2

Telegram linking should be OPTIONAL.

Because:

  some borrowers may not use Telegram
  some groups are offline-managed

Rule 3

Borrower should NOT be deleted if Telegram unlinked.

Keep loan history intact.

Use:

  verification_status

instead.

Rule 4

Always support manual fallback.

Because Telegram privacy settings may block:

  forward_from
