Loan Repayment & Late Penalty System Plan

1. PPLAN GOAL

Build a Telegram-first loan management system where:

  -admins manage loans inside Telegram groups
  -borrowers pay monthly installments
  -overdue payments receive automatic daily penalties
  -Telegram bot sends reminders automatically
  -next monthly due date stays fixed even if borrower pays late

2. CORE BUSINESS RULES
--Repayment Rule
  Monthly fixed repayment schedule

Example:

| Installment | Due Date |
| ----------- | -------- |
| #1          | Jan 1    |
| #2          | Feb 1    |
| #3          | Mar 1    |

--Late Payment Rule

If borrower pays late:

✅ add daily penalty
✅ send overdue reminders
❌ DO NOT shift next due date

Example:

| Item                | Value  |
| ------------------- | ------ |
| Monthly installment | $100   |
| Daily penalty       | $2/day |
| Due date            | Jan 1  |
| Paid date           | Jan 6  |

Result:
| Calculation      | Amount |
| ---------------- | ------ |
| Base installment | $100   |
| Late penalty     | $10    |
| Total due        | $110   |

Next due date still:
  Feb 1

Phase 3 — Daily Automation
cPanel Cron Job

Runs Laravel Scheduler every minute.

Example:
* * * * * php /home/username/public_html/artisan schedule:run

Laravel Scheduler

Runs daily penalty command.

Example:
$schedule->command('loans:process-overdue')->dailyAt('08:00');

Phase 4 — Overdue Processing
Command Flow

Laravel command:
  loans:process-overdue
Responsibilities:

STEP 1
Find overdue installments.
Query:
  status != paid
 AND due_date < today

STEP 2
   Calculate late days.
Example:
  today - due_date
Result:
  5 days late

STEP 3
Calculate penalty.
Example:
  5 × $2/day
Result:
  $10

STEP 4
Update installment.
Example:
| Field            | Value   |
| ---------------- | ------- |
| penalty_amount   | $10     |
| remaining_amount | $110    |
| late_days        | 5       |
| status           | overdue |

STEP 5
Save penalty log.
Example:
| Date  | Penalty |
| ----- | ------- |
| Jan 2 | $2      |
| Jan 3 | $2      |
| Jan 4 | $2      |

STEP 6
Queue Telegram reminder.

--Phase 5 — Telegram Reminder System
Reminder Conditions
Send reminder ONLY IF:

  status = overdue
  AND remaining_amount > 0

Telegram Reminder Example

  ⚠️ Installment Overdue
  
  Borrower: @john
  Installment: January
  Base Amount: $100
  Penalty: $10
  Total Due: $110
  Late Days: 5

  Please contact admin immediately.

Reminder Frequency
Recommended:
  once per day
NOT every hour/minute.

--Phase 6 — Payment Flow
Admin Receives Payment

Admin records payment:

Example:
$110 paid

Laravel Actions
STEP 1
Create payment record.

STEP 2
Update installment.
Example:

| Field            | Value             |
| ---------------- | ----------------- |
| paid_amount      | $110              |
| remaining_amount | $0                |
| status           | paid              |
| paid_at          | current timestamp |

STEP 3
Stop reminders automatically.
Because:
  status = paid

IMPORTANT
Next due date remains fixed.

Example:
  Feb 1

NOT shifted to:
  Feb 6

Option A — Fixed Daily Penalty (RECOMMENDED MVP)

Example:

Best for MVP.

Option B — Percentage-Based Daily Penalty

Example:
  1% daily

Formula:
remaining_amount × percentage

More complex.

7. TELEGRAM BOT RESPONSIBILITIES
Bot Responsibilities
Send:

✅ loan creation messages
✅ overdue reminders
✅ payment confirmations
✅ installment updates

Bot DOES NOT:

❌ calculate penalties directly
❌ handle business logic

Laravel backend handles calculations.

Telegram only displays results.
